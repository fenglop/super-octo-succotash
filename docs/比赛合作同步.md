## 三、学习伴侣 Agent 产品定位

### 一句话定义
一个以 Obsidian 个人知识库为记忆、能帮助用户查笔记、整理知识、推荐学习路径的 AI 学习伴侣。

### 目标用户
- 大学生，理工科方向
- 日常积累大量笔记但缺乏整合和复盘习惯
- 有清晰的学习领域但缺少系统性跟踪

### MVP 核心能力
1. **知识库问答**：用户提问 -> Agent 从笔记中检索 -> 整理回答
2. **领域概览**：按分类返回该领域的知识状态
3. **诚实标注**：区分"知识库内容"和"模型推断"

### 产品设计报告六块
1. 产品概述 - 背景、目标、价值、用户
2. 市场定位 - 竞品分析、差异化
3. 需求分析 - 痛点、需求分级
4. 功能设计 - 模块、交互流程
5. 技术实现 - 架构、知识库、工作流
6. 应用与效果 - 场景、预期、推广
