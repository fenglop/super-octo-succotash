## 二、产品定位

### 一句话定义
一个以个人知识库为记忆、能帮助用户查笔记、整理知识、推荐学习路径的 AI 学习伴侣。

### 目标用户
- 大学生，理工科方向
- 日常积累大量笔记但缺乏整合和复盘习惯

### MVP 核心能力
1. 知识库问答：用户提问 -> Agent 从笔记中检索 -> 整理回答
2. 领域概览：按分类返回该领域的知识状态
3. 诚实标注：区分"知识库中的内容"和"模型推断的内容"

### 核心差异点
- 绑定用户的个人笔记体系，而非通用知识
- 严格区分事实与推断，让用户知道可信度
- 理解用户的学习状态
