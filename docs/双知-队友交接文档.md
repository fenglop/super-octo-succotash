## 一、项目概览

知境是一款以个人知识库为核心的 AI 学习伴侣 Agent。它深度绑定用户的个人笔记体系（Obsidian），能理解用户的真实学习状态，并基于此提供个性化问答、知识梳理和学习路径建议。

核心差异点：
1. 绑定用户的个人笔记体系，而非通用知识
2. 严格区分'知识库中的事实'与'模型的推断'，标注可信度
3. 理解用户的真实学习状态

## 四、AI Agent 理论积累（核心技术基础）

### 核心公式
Agent = 模型 + Tool + Skill + Memory + Workflow

- 模型：大脑，理解语言和推理
- Tool：手脚，单一执行能力
- Skill：方法，多个 Tool 组合
- Agent：规划者，理解目标 -> 规划 -> 执行 -> 观察 -> 调整
- Memory：短期（对话上下文）+ 长期（Obsidian）
- Workflow：多步流程编排

### Router 策略
复杂推理 -> GPT / 代码 -> DeepSeek / 简单任务 -> 小模型

### AI 幻觉三层验证
- 事实（来源代码/文档/实验，可信）
- 推断（基于事实，需标注）
- 未知（需验证）

### 实践路线（已规划待执行）
单Agent -> Skill组合 -> Memory设计 -> Multi-Agent -> 机器人结合

## 五、小车项目技术状态（并行项目）

### 硬件
树莓派 4B 4GB + TB6612 x 2 + MG310 电机 x 4 + USB 摄像头
双路独立供电（充电宝 + 12V 锂电池组）

### GPIO 接线
左前(LB): GPIO17/27/PWM25
右前(RB): GPIO22/23/PWM24
左后(RF): GPIO5/6/PWM12
右后(LF): GPIO13/19/PWM18

### 软件架构
car_run_final.py（主循环）
  -> vision.py（红色HSV识别 + 形态学 + 中心点 + 平滑）
  -> keyboard_control.py（手动WASD控制）
  -> coolspot_motor.py（底层四轮驱动）

### 关键参数
Kp=0.045 Ki=0.0 Kd=0.003
FORWARD_SPEED=20 RAMP_STEP=10 MIN_AREA=800
HSV红1: [0,100,80]->[10,255,255]
HSV红2: [160,100,80]->[180,255,255]
分级控制：进入条件 error>100 + 面积500-2000

## 六、硬件踩坑经验

1. 供电必须双路独立（树莓派用充电宝，电机用电池组，共地不共正极）
2. CSI 卡扣脆弱，坏了换 USB 摄像头
3. 轮子命名：LB=左前 RF=左后 LF=右后 RB=右前
4. 带电插拔 GPIO 可能烧板
5. Python 缩进统一 4 空格
6. HSV 红色需合并两个 H 区间（0-10 和 160-180）
7. PID 从小逐步调大
